このプロジェクト（mitumori）の作業を引き継ぐ。ユーザーは別アカウント・別パソコンかもしれない。
次の順に実行し、最後に日本語で短く報告する。専門用語は使わず、中学生にも分かる言葉で書く。

1. **読む**: `docs/引継ぎ_曲げ逆算.md` と `CLAUDE.md`。曲げ見積り計算書を触るなら
   `曲げ見積り計算書_実装メモ.md` も読む。

2. **場所の確認**: `python tools/update_gyakusan.py` を実行する。
   - 成功したら、データ期間・曲げ明細数・足りない欄・逆算候補の数を控える。
   - 「見つかりません」で止まったら、環境変数 `MITUMORI_ARCHIVE` / `MITUMORI_PDF_ROOT`、または
     `tools/paths.json` で場所を教えてもらう必要がある。ユーザーに場所を聞く（勝手に探し回らない）。

3. **画面を出す**: ポート 8765（このフォルダ）と 8766（見積回答PDFのフォルダ）で
   ローカルサーバーを起動し、`http://localhost:8765/曲げ逆算ダッシュボード.html` を案内する。
   既に動いていれば起動し直さない。ユーザーが自分で開く場合は `逆算ダッシュボード起動.bat` を案内。

4. **今の状態を報告**: 次を短い表と箇条書きで伝える。
   - データ期間と件数（2の結果）、逆算候補と「使えそう」の件数
   - 計算書に登録済みの逆算実績の件数（`data/gyakusan/history.csv` の最終行、または
     ダッシュボード画面の「登録済み」）
   - 残っていること（`docs/引継ぎ_曲げ逆算.md` の「7. 残っていること」）
   - 次にやると良いこと1つだけを提案する

## 守ること

- PDFの読み取り（トークンを使う作業）はここではやらない。「受注・見積自動処理システム要件定義」
  チャットの担当。二重処理は金額の事故になる。
- **このリポジトリは公開。** 得意先名・単価を含む `曲げ逆算ダッシュボード.html`、`data/gyakusan/` は
  コミットしない（.gitignore 済み。git add -A の前に `git status` で必ず確認）。
- 計算書の実績（GAS）は配列まるごと上書きなので、書き込む前に必ず最新を読む。
- 実績の登録・取り消しはユーザーの操作。こちらから勝手にGASへ書き込まない。
