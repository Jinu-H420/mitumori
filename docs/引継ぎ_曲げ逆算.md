# 引継ぎ — 曲げ逆算ダッシュボード（2026-09-30 時点）

別のアカウント・別のパソコンで続きをやるための説明。Claude Code では **`/引継ぎ`** と打てば、
この文書を読んで現状を確認し、サーバーを起動するところまで自動で行う。

## 1. 何をやっているか

曲げ見積り計算書（曲げ工賃だけを出すアプリ）の単価表を、実績で裏付けて育てるのが目的。

- 社長が答えた工賃は F1 で実績に登録される。しかし 280欄（7形状 × 8重量帯 × 5長さ）のうち
  257欄が0〜2件しかなく、単価表を直す根拠が足りない。
- そこで、**過去の見積回答PDF**（材料込みの単価が書いてある）から曲げ工賃を逆算し、
  実績の少ない欄を埋める。それが「曲げ逆算ダッシュボード」。

## 2. 全体の流れ

```
社長の回答 ──F1──────────────────┐
                                  ├→ 計算書の実績（GAS）→ 単価表の見直し
過去の見積PDF                     │
  └→ 別チャットがデータ化         │
      items.jsonl                 │
        └→ 逆算ダッシュボード ────┘
            PDFを見て内訳を合わせ「使える」→「計算書に登録」
```

## 3. できているもの

| 機能 | 状態 |
|:---|:---|
| 実績が足りない欄の集計 | 済 |
| 過去見積からの逆算・PDF並べての確認画面 | 済 |
| 内訳あわせ（材料費・切断費・穴代・曲げ工賃を入れて見積金額を再現） | 済 |
| 「使える」判定 → 計算書の実績に登録（逆算バッジ付き） | 済。**まだ実際には1件も登録していない** |
| 蓄積の推移記録（data/gyakusan/history.csv） | 済 |

## 4. 使い方

1. `逆算ダッシュボード起動.bat` をダブルクリック（ダッシュボードが無ければ自動で作る）。
2. 左の一覧で案件をクリック → 右にPDF。
3. 内訳の表で、材料費・切断費・穴代を直す。「残りを入れる」で曲げ工賃に残りが入り、
   合計が見積金額に一致する（緑＝ほぼ一致）。**見積金額を再現できたときの曲げ工賃が答え。**
4. 納得できたら「使える」→ 右上「計算書に登録」。取り消しは各案件の「登録を取り消す」。
5. データが増えたら `python tools/update_gyakusan.py` で作り直す。

## 5. 数字の出どころ

- 逆算の初期値: 見積単価 − 切板代（重量 × 185円/kg、t3.2・t4.5は190円）− 穴代（50円/個）
- 重量: 板厚 ×（長辺＋余長）×（短辺＋余長）× 7.85 ÷ 1,000,000。余長は t≤2.3→50、t3.2→30、
  t≥4.5→20、ボンデ→100（計算書と同じ）
- 候補にするのは、社長の直接回答が0〜2件の欄に当たるもの。縞板・SUS・小物（5kg以下かつ835mm以下）は除外。

## 6. 担当の分け方（重要）

- **PDFの読み取り（トークンを使う作業）は「受注・見積自動処理システム要件定義」チャットの担当。**
  ここでは読み取らない。二重処理は金額の事故になる。
- mitumori 側は `items.jsonl` を読むだけ。

## 7. 残っていること

- 実際に1件登録して、計算書の実績一覧で「逆算」バッジを確認する（未実施）。
- 1年分の蓄積: いまのデータは 2025-08〜2026-09。2025-09〜12 の 2,195件が未読み取り。
  依頼するときは、小さい画像で曲げかどうか判定 → 曲げだけ本読み、の順でトークンを抑える。
- 四方曲げ 20〜30kg は逆算が表より 2,000〜3,400円高い。件数が貯まったら単価表の見直し候補。

## 8. 注意

- **このリポジトリは公開。** 得意先名・単価を含む `曲げ逆算ダッシュボード.html` と `data/gyakusan/` は
  .gitignore 済み。絶対にコミットしない。
- 計算書の実績（GAS）は配列まるごと上書き。登録直前に最新を読んでから足すこと。
- 判定・内訳の入力値はブラウザごとの保存（localStorage）。パソコンをまたいで引き継がれない。
  登録済みの実績は GAS なのでどこからでも見える。
