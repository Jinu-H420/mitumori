# 曲げ工賃の計算（高橋鉄骨）

曲げ加工賃**だけ**を出す。材料費・切断費・穴あけは含まない。
Webアプリ「曲げ見積り計算書」と**同じ計算**をスクリプトで行う。

- アプリ: https://jinu-h420.github.io/mitumori/曲げ見積り計算書.html
- 正本: `曲げ見積り計算書.html` の定数。このスキルの `scripts/bend_tables.json` はそこから自動生成したもの。

## まず最初に ― 暗算で答えない

重量帯・長さ区分の表引きと、オプションの掛け算・足し算の順番がある。暗算すると必ずずれる。
**同梱のスクリプトを走らせること。**

```bash
cd <このスキルのフォルダ>/scripts
python bend_calc.py --test     # 計算書と照合した14例。全部OKならそのまま使える
```

Python3があれば動く（標準ライブラリのみ。pip install 不要）。

### 1件だけ計算する

```bash
python bend_calc.py --shape コの字曲げ --t 4.5 --tate 400 --yoko 2000 --qty 2
python bend_calc.py --shape L曲げ --t 6 --tate 500 --yoko 1500 --opt 中押し --opt ハゼ折
python bend_calc.py --shape 'L曲げ（短）' --t 4.5 --tate 300 --yoko 1200 --shima
python bend_calc.py --shape L曲げ --t 1.6 --tate 100 --yoko 300 --komono
```

重量と曲げ長さが分かっていれば寸法なしでもよい: `--weight 37.2 --length 1500`

### Python から使う

```python
import bend_calc as b
r = b.keisan(shape='四方曲げ', t=3.2, tate=900, yoko=1000, qty=1)
r['total']       # 1個あたりの曲げ工賃（円・税抜）
r['breakdown']   # 計算の順番（そのまま説明に使える）
```

### まとめて計算する

列は `形状,板厚,縦,横,数量,材質,曲げ回数,オプション,小物`（後ろ4列は空でよい）。

```bash
python bend_calc.py 明細.csv -o 明細_calc.csv
```

## 計算の決まり

1. **重量** ＝ 板厚 ×（縦＋余長）×（横＋余長）× 7.85 ÷ 1,000,000。
   余長は 板厚2.3以下→50mm、3.2→30mm、4.5以上→20mm。
   縞板は 7.85 ではなく板厚ごとの単位重量（kg/m²）を使う。
2. **曲げ長さ** ＝ 既定では横（W）。縦を使うときは `length_source='L'`。
3. **表引き** ＝ 形状の表で、重量は「入力以上の最小の行」、長さは「入力以下の最小のしきい値の列」。
   長さの区分は 〜835 / 〜1670 / 〜2505 / 〜3048 / 3048超（mm）。
   重量の帯は 〜10 / 20 / 30 / 50 / 80 / 100 / 150 / 150超（kg）。
4. **複数曲げ** は C型曲げ（4回）の表を使い、`表の値 × 回数 ÷ 4` にする。
5. **数量係数**（既定は**使わない**）。使うときは 1〜4個→×1.5、5〜19個→×1.0、20個〜→×0.8。
6. **オプション**（上から順に適用。掛け算と足し算が混ざるので順番が効く）
   中押し ×1.5 → 逆曲げ ×1.2 → 長尺目押し +2,500円 → ブロック +3,000円 → ハゼ折 +2,000円。
   長尺目押しは曲げ長さ1,000mm以上のときだけ付く。
7. **小物モード**（重量5kg以下 **かつ** 曲げ長さ835mm以下のときだけ使える）
   曲げ回数ごとの単価（1回400／2回500／3回600／4回800／5回1,000／6回1,200／7回1,500／8回1,800円）。
   回数は形状から決まる（L曲げ=1、Z・コの字=2、三方=3、C型・ハット・四方=4）。複数曲げのときだけ指定する。
   数量係数をかけたあと、1個あたり最低300円。オプションは 中押し・逆曲げ・ハゼ折 の3つだけ。
8. 出る金額は **1個あたり・税抜**。

## パラメーターを聞かれたとき

単価表・余長・曲げ回数・数量係数・オプション・小物の値は、**全部** `references/parameters.md` に表でまとめてある
（`scripts/bend_tables.json` と同じ中身を人が読める形にしたもの）。
「コの字曲げの単価表は？」「PL4.5 の余長は？」「パラメーターを全部見せて」と聞かれたら、このファイルを読んで該当の表をそのまま見せる。
覚えている数字で答えない。

## 形状の名前

- 通常鋼板: L曲げ / Z曲げ / コの字曲げ / C型曲げ / ハット曲げ / 三方曲げ / 四方曲げ / 複数曲げ
- 縞板（CHP）: L曲げ（短）/ L曲げ（長）/ コ/Z（両端短）/ コ/Z（片側混在）/ コの字（長）/ C型/ハット / 三方曲げ / 四方曲げ

呼び方が違っても次のように読み替える: ハット＝帽子型、コの字＝チャンネル、複数曲げ＝曲げ回数を指定したいとき。

## 答え方

- 金額だけでなく、**どの行・どの列を引いたか**（例: 〜50kg × 〜1670mm）を1行添える。`breakdown` をそのまま使う。
- 寸法や形状が分からないときは、推測で埋めずに聞く。特に **曲げ長さが縦か横か**、**曲げ回数**、**数量**。
- 材料費・切断費・穴あけを聞かれたら、このスキルの範囲外だと伝える（材料込みは別の計算書）。

## 単価を変えるとき

価格の正本は `曲げ見積り計算書.html` の定数（BENDING_TABLE / SHIMA_* / KOMONO_DEFAULT_TABLE）。
**このスキルの json を手で直さない。** HTMLを直してから、mitumori リポジトリで次を実行して写す。

```bash
python tools/export_bend_tables.py    # bend_tables.json と references/parameters.md を作り直す
python skills/mage-koutin/scripts/bend_calc.py --test
```

`--test` は計算書の実測値と照合しているので、変えた直後に必ず走らせる。
