# 曲げ工賃のパラメーター一覧（全部）

曲げ見積り計算書.html（価格の正本）から自動で作ったもの。**手で直さない。**
直すときは HTML を直して `python tools/export_bend_tables.py`。
金額はすべて 1個あたり・税抜・円。

## 1. 重量の出し方

- 通常鋼板: 板厚 ×（縦＋余長）×（横＋余長）× 7.85 ÷ 1,000,000（kg）
- 縞板: 単位重量（kg/m²）×（縦＋余長）×（横＋余長）÷ 1,000,000（kg）

| 板厚 | 余長（縦・横それぞれ） |
|:---|---:|
| 2.3mm 以下 | 50mm |
| 2.3mm 超 〜 3.2mm | 30mm |
| 3.2mm 超 | 20mm |

| 縞板の板厚 | 単位重量（kg/m²） |
|:---|---:|
| 2.3 | 19.73 |
| 3.2 | 26.79 |
| 4.5 | 36.99 |
| 6.0 | 48.77 |
| 9.0 | 72.32 |
| 12.0 | 95.87 |

## 2. 曲げ回数（形状から決まる）

| 形状 | 回数 |
|:---|---:|
| L曲げ | 1 |
| Z曲げ | 2 |
| コの字曲げ | 2 |
| C型曲げ | 4 |
| 三方曲げ | 3 |
| 四方曲げ | 4 |
| ハット曲げ | 4 |
| 縞板 L曲げ（短） | 1 |
| 縞板 L曲げ（長） | 1 |
| 縞板 コ/Z（両端短） | 2 |
| 縞板 コ/Z（片側混在） | 2 |
| 縞板 コの字（長） | 2 |
| 縞板 C型/ハット | 4 |
| 縞板 三方曲げ | 3 |
| 縞板 四方曲げ | 4 |

複数曲げは C型曲げ（4回）の表を使い、表の値 × 回数 ÷ 4。

## 3. 表の引き方

- 重量: 入力以上の最小の行
- 曲げ長さ: 入力以上の最小の列（既定は横の寸法）
